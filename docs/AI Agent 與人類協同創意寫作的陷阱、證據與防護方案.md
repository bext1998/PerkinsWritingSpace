AI Agent 與人類協同創意寫作的陷阱、證據與防護方案

調查研究報告｜資料截點：2026 年 7 月 17 日

本報告討論人類與生成式 AI Agent 共同進行小說、劇本、散文、腳本與其他創意寫作時，可能出現的系統性風險。核心問題不是「AI 能不能寫」，而是：當 AI 介入構思、選擇、改寫、評估與發布等多個環節後，創作者是否仍能保有方向、判斷、聲音、責任與可追溯性。

# 一、執行摘要

目前最可靠的研究訊息可濃縮為三點：

* AI 輔助可能提高單篇作品的平均評價、完成速度與可讀性；但個體收益不等於整體創作生態收益。多數人依賴相近的 AI 建議時，作品之間可能變得更相似，創意分布的尾端被壓縮。  
* 人類容易把「語言流暢、結構完整、回覆自信」誤認為「正確、原創、適合我的作品」。這會造成自動化偏誤、錨定、過早收斂與查證下降。  
* 最危險的流程不是偶爾請 AI 改句子，而是把 AI Agent 放在創作者尚未形成意圖之前，讓它同時提出方向、產生內容、評選內容、修飾內容，再以自己的輸出作為下一輪上下文。這會把代理的偏好變成創作規範。  
* 面對非絕對確定性的決策，LLM 不應強行輸出唯一答案；應分辨歧義、知識缺口、價值取捨與模型限制，並在「直接回答、條件式建議、暫緩／升級」之間切換。

因此，建議採用「人類持有創作主權，Agent 分工支援探索與檢驗」的協作模型：人類先定義想表達什麼，AI 再協助擴張可能性；AI 可以批評與查核，但不應同時擔任唯一的發想者、作者、評審與事實裁判。

# 二、研究範圍與證據分級

本報告綜合生成式 AI、創意寫作、人機互動、認知心理學、自動化研究、文化演化與著作權政策資料。因 AI Agent 協同小說創作仍是新興領域，部分結論是由相鄰領域的直接實驗結果推導出的設計假說，而不是已被長期縱向研究完全證實的定律。

| 證據層級 | 本報告的使用方式 |
| :---- | :---- |
| 直接實驗／同儕審查研究 | 作為主要判斷依據，例如生產力、創意評價、作品相似度、AI 文字辨識與自動化偏誤。 |
| 理論／跨領域模型 | 用來解釋可能的長期機制，例如文化棘輪、認知卸載與模型崩潰。 |
| 政策／官方報告 | 用來界定著作權、作者資格、揭露與責任的現況；不把單一法域結論擴張成全球法律結論。 |
| 分析性推論 | 明確標為「推論」或「待驗證假說」，尤其是人類創作流程中的長期棘輪效應。 |

# 三、先釐清「穆勒棘輪」與相關棘輪概念

## 3.1 穆勒棘輪不是創意同質化的正式名稱

Müller’s ratchet（穆勒棘輪）原本是族群遺傳學概念：在缺乏重組的無性族群中，最少有害突變的族群可能因隨機漂變而永久消失，使有害突變負荷逐步累積。它不是專門描述 AI、寫作或文化的理論。若直接把「AI 讓創意越來越差」稱為穆勒棘輪，容易造成概念錯置。

## 3.2 更適合本題的「文化棘輪」與「回饋退化」

文化演化研究使用「文化棘輪」描述創新被高保真傳遞、保留並在後續世代上加以修改，使複雜文化累積而不容易退回原點。這個概念本身可以是正向的。放到 AI 協同寫作，真正需要防範的是「負向文化棘輪」：便利的模型慣例被大量複製，創作者再把 AI 修飾後的作品餵回公共網路、提示庫或未來模型，最後使某些少見的敘事、方言、節奏、價值觀與個人聲音逐漸消失。

這裡存在兩條不同的回饋鏈：

* 人類—作品回饋鏈：人類接受 AI 的語言與敘事慣例 → 作品更像模型常見答案 → 讀者與平台獎勵這種風格 → 下一輪創作者更依賴相同慣例。  
* 資料—模型回饋鏈：AI 生成內容進入網路與資料集 → 後續模型學到更多合成內容 → 分布尾端、罕見風格與原始人類訊號被稀釋。Nature 的模型崩潰研究直接支持第二條鏈的技術風險，但不能直接證明每一位小說作者都會發生同樣程度的創意退化。

# 四、主要陷阱與形成機制

| 陷阱 | 形成機制 | 可能後果 | 優先度 |
| :---- | :---- | :---- | :---- |
| 個體品質提升、群體多樣性下降 | AI 建議把低品質作品拉高，但把多數人拉向相近的高機率解法。 | 單篇更順，整體更像；少見題材與非主流敘事減少。 | 高 |
| 早期錨定與創意過早收斂 | 第一批 AI 方案成為預設答案，後續探索只在其框架內微調。 | 人類原本可能提出的怪點子、個人經驗與非標準結構被淘汰。 | 高 |
| 自動化偏誤與權威幻覺 | 流暢、自信、快速的輸出被誤認為正確或更專業。 | 錯誤設定、虛構資料、錯誤引用與不適合的情節被保留。 | 高 |
| 認知卸載與技能退化 | 把構思、取捨、改寫與理由說明全部外包給 Agent。 | 創作者對作品的掌握下降，長期難以獨立創作或診斷問題。 | 高 |
| 聲音與作者身分稀釋 | AI 將個人語氣轉成平均化、可接受、可預測的語言。 | 作品有「完成感」但缺乏作者不可替代的觀點與節奏。 | 高 |
| 資料污染與回饋退化 | AI 輸出被當成原始資料，再被後續模型或 Agent 重複使用。 | 錯誤與慣例被放大，罕見訊號消失；這是長期生態風險。 | 中高 |
| 著作權、近似模仿與來源不明 | 模型可能產生訓練資料中的近似片段，或依照特定作者風格產生可辨識模仿。 | 侵權爭議、署名不清、無法證明人類創作貢獻。 | 高 |
| Agent 目標漂移與流程黑箱 | Agent 自行拆任務、重寫規則、引用上一輪輸出，卻未讓人類確認中間決策。 | 故事方向悄悄改變，錯誤被多輪工作流合理化。 | 高 |
| 文化與語言偏差 | 訓練資料與獎勵偏好較集中於主流語言、類型與市場。 | 地方經驗、台灣語境、少數方言與非西方敘事被翻譯成通用模板。 | 中高 |

## 4.1 個體品質與群體多樣性的矛盾

Doshi 與 Hauser 在 Science Advances 的創意寫作實驗發現，取得 AI 產生的故事構想後，作品平均被評為更有創意、寫得更好且更有趣，對原本創意能力較低的參與者尤其有幫助；但使用 AI 的作品彼此相似度也更高。這代表「AI 讓我這篇寫得更好」與「大家的作品變得比較像」可以同時成立。

這是協同寫作最容易被忽略的尺度問題：創作者通常評估單一作品，平台或文化則承受整體作品分布的變化。若成功標準只看可讀性、完成速度與讀者平均評分，系統會偏好可複製的中高品質模板，卻不會自動保護異質性。

## 4.2 錨定、固定與「看見答案後就回不去」

AI 在寫作早期提供的不是中性工具，而是具體的語句、角色、衝突與情節選項。具體答案會佔據工作記憶，讓人類從「我想要什麼」轉向「這個答案哪裡可以修改」。這會把創作模式從生成式探索轉成評選式編輯。評選能力固然重要，但若在作者尚未建立核心意圖前就開始評選，AI 的先手優勢會悄悄變成作者的方向。

Agent 化後，這個效應會被放大：Agent 可以一次生成十個方案、淘汰八個、整合兩個，再自動進入下一輪。若人類只在最後看成品，實際上已經把最重要的取捨交給代理。

## 4.3 自動化偏誤、流暢性與幻覺

Parasuraman 與 Riley 將 automation misuse 定義為在自動化表現不佳時仍過度依賴，並指出信任、工作負荷與風險會影響人類是否採用自動化。對寫作而言，錯誤不一定以明顯的機器故障出現；它可能是一段語法漂亮、情緒合理、卻不符合世界觀的設定。

Jakesch、Hancock 與 Naaman 的六項實驗顯示，參與者很難可靠辨認 AI 生成的自我介紹，且會使用有系統但不可靠的語言線索作判斷。這提醒我們：人類對「像人寫的文字」的直覺並不等同於對內容真實性、原創性或作者性的可靠判斷。

對創意寫作的直接風險包括：虛構不存在的文獻、混淆角色設定、錯置歷史時間、把推測寫成事實，以及在作品中留下作者沒有真正理解的心理或文化描寫。Ji 等人的幻覺調查指出，生成式語言系統的流暢性與事實可靠性不是同一件事。

## 4.4 認知卸載、技能退化與所有權感

把重複性工作交給工具不必然有害；問題在於被卸載的是否正是創作者需要鍛鍊的判斷能力。若 Agent 同時負責發想、組織、寫句子、挑選、評論與修訂，人類可能只剩下「接受／拒絕」按鈕。久而久之，創作者不只是少打字，而是少做形成作者性的決策。

這也會影響 ownership：作品即使客觀上變好，創作者仍可能覺得它不像自己、說不清某段為何存在，或在修改時無法定位問題。近年的 HCI 綜述將寫作拆成規劃、轉譯、審閱與監控等階段，指出不同作者對 AI 介入點的需求不一；創意作者往往更重視對轉譯與審閱的控制，而不是把核心意圖在規劃階段交出去。

## 4.5 風格同質化與負向文化棘輪

同質化不只表現在「大家都用相同形容詞」，也可能出現在更深層的結構：衝突出現的時間、角色弧線的節奏、段落長度、反轉方式、對話的禮貌程度、情緒收束方式與「什麼算合理的故事」。

文化棘輪的正向條件是高保真傳遞加上持續創新；AI 協同寫作若只保留高頻、易評分、易複製的方案，便可能只保留傳遞而削弱創新。這不是說 AI 必然摧毀創意，而是說協作系統的目標函數若只獎勵「好讀」「像成熟作品」「符合類型」，就會讓創新成本高於模仿成本。

Shumailov 等人對模型崩潰的研究提供了技術上的類比：當模型反覆從模型生成資料學習，原始分布的尾端會逐步消失。把這個結果直接等同於人類創意會崩潰是不恰當的；但它足以支持一個值得監測的假說：若創作者、平台與模型形成自我引用的內容循環，少見的人類訊號可能比高頻模板更容易被稀釋。

## 4.6 著作權、近似模仿與作者責任

著作權問題至少分成三層，不能混為一談：模型如何取得訓練資料；模型是否輸出近似受保護內容；以及人類對最終作品做了多少具有表達性的選擇與修改。美國著作權局 2025 年報告的結論是，提示詞本身通常不足以形成對輸出的充分控制，但人類可對 AI 輸出中可辨識的人類創作、創意選擇／編排與創意修改取得保護；這是美國政策分析，不代表台灣或其他法域的最終法律判斷。

此外，Carlini 等人的研究已證明，特定語言模型可能在查詢下吐出訓練資料中的逐字片段，包括個人資料、對話、程式碼與其他文本。因此，創作者不應把「模型生成」自動視為「無來源、無風險、可自由使用」。

# 五、建議的協同創作架構

建議把人類與 Agent 的關係設計成「分工式創作系統」，而不是讓 Agent 充當全自動作者。基本原則如下：

1. 人類擁有目標與價值判斷：主題、想說的話、不可妥協的世界觀、角色倫理與作品邊界由人類先定義。  
2. Agent 擁有探索與檢驗職責：提出可能性、尋找矛盾、模擬讀者反應、整理資料與指出缺口，但不自動替人類決定核心方向。  
3. 每一輪都要能回溯：保存人類原始意圖、Agent 建議、採用理由、修改差異與查證來源。  
4. 至少保留一條無 AI 的創作路徑：定期讓作者獨立寫作、回憶設定與自行提出方案，用來維持能力與辨識自己的聲音。  
5. 把品質與多樣性同時納入驗收：不只問「這段好不好」，也問「它是否只是最常見的好答案」。

## 5.1 建議工作流：六階段人機分工

| 階段 | 人類負責 | Agent 可以做 | 不可直接交給 Agent 的事項 |
| :---- | :---- | :---- | :---- |
| 0\. 意圖種子 | 寫下主題、情緒、個人經驗、問題意識與限制。 | 協助整理成簡短創作契約。 | 核心命題與作品要說什麼。 |
| 1\. 無 AI 發散 | 先獨立產生若干粗糙、怪異或互相矛盾的想法。 | 只在被要求時記錄、分類，不主動補成完整故事。 | 第一批創意與主要方向。 |
| 2\. 受控擴張 | 指定探索維度與淘汰標準。 | 從不同視角提出方案、反例與跨類型聯想。 | 替人類自動選出唯一最佳方案。 |
| 3\. 人類選擇與重組 | 選擇、混合、改寫並說明採用理由。 | 追問矛盾、檢查因果、提出尚未考慮的代價。 | 以相似度或偏好分數取代作者判斷。 |
| 4\. 草稿與批評 | 寫出主草稿，保留個人語氣。 | 做結構審閱、角色一致性檢查、事實查核與讀者模擬。 | 同時擔任作者與最後裁判。 |
| 5\. 發布前稽核 | 逐段確認內容、來源、權利與署名。 | 產生查核清單、差異報告與風險摘要。 | 無人類閱讀就自動發布。 |

## 5.2 具體防護措施

* 延後 AI：在規劃階段先完成「人類意圖種子」與至少一版無 AI 草案；越靠近核心創意，越應提高人類主導比例。  
* 角色分離：不要讓同一個 Agent 同時發想、寫作、評分與批准。可分成發散 Agent、邏輯審查 Agent、資料查核 Agent，最後由人類裁決。  
* 強制多樣性：要求輸出彼此差異明確的方案，並使用「反類型」「低機率但合理」「地方語境」「不依賴既有模板」等探索條件；多樣性不是把 temperature 調高就能保證。  
* 保留未採用分支：把被淘汰的想法存入 Ideas 或創作日誌，避免 Agent 以單一路徑的後續結果假裝原本只有一個合理方向。  
* 人類重寫檢查：對關鍵段落先讓作者看結構與要點，關閉 AI 後自行重寫，再用 Agent 做差異比較；這能測量作品是否仍然具有作者掌握。  
* 查證與來源帳本：凡是歷史、科學、地理、法律、人物、真實事件與引用資料，都要記錄來源、查證日期、可信度與是否由 AI 提供線索。  
* 敏感資料隔離：不要把未公開小說、私人日記、他人可識別資料、合約或受限制素材直接送入不清楚資料保留政策的服務。  
* 風格邊界：可描述作品需要的形式特徵，例如句子長度、節奏、視角與意象密度；避免把提示寫成模仿在世作者或特定作品的可識別風格。  
* 發布閘門：Agent 只能提出「可發布」建議，不能擁有最終發布權；最後必須由人類閱讀全文並確認責任。

# 六、LLM 如何應對非絕對確定性的決策

創意寫作裡的大多數決策都不是「正確／錯誤」二選一：角色是否應該背叛、結局是否要保留曖昧、哪個敘事視角更適合、某個設定是否值得冒險，都涉及不完整資訊、價值取捨與作者偏好。因此，LLM 不應把所有問題都處理成尋找唯一答案，而應先判斷不確定性來自哪裡，再決定是補充資訊、保留分支、提出條件式建議，或請人類接手。

## 6.1 先分辨五種不確定性

| 類型 | 意思 | 適當的模型行為 | 創意寫作例子 |
| :---- | :---- | :---- | :---- |
| 輸入／語意不確定性 | 使用者的要求含糊、互相矛盾或缺少關鍵條件。 | 指出歧義，提出少量高價值澄清問題；若不影響進度，可列出假設後繼續。 | 「黑暗結局」是悲劇、開放式結局，還是道德代價較高？ |
| 知識／證據不確定性 | 模型缺乏可靠資料，或資料彼此衝突。 | 把已知、未知、推測分開；要求外部來源或查證，不用語氣掩蓋缺口。 | 某歷史制度是否在故事年代已存在。 |
| 世界／結果不確定性 | 即使資料完整，未來結果仍有多種可能。 | 提供情境、機率區間或條件式結果，不宣稱必然。 | 讀者可能如何解讀一個留白結局。 |
| 規範／價值不確定性 | 不同目標之間沒有客觀唯一最優解。 | 先呈現取捨，詢問或沿用使用者的價值排序。 | 商業可讀性與實驗性之間要偏向哪一邊。 |
| 模型／流程不確定性 | 模型可能誤解、漏掉長上下文，或 Agent 的工具鏈不可靠。 | 交叉檢查、保存版本、設置停止條件與人工升級，不把自我解釋當成證明。 | Agent 重寫多輪後遺失角色初始動機。 |

## 6.2 不要把「口頭信心」當成可靠機率

讓 LLM 回答「我有 80% 信心」是一種有用的溝通介面，但不能直接視為校準過的機率。研究顯示，語言模型的 verbalized uncertainty 可能與真正的正確率不一致；模型也可能在內容錯誤時使用流暢而肯定的語氣。更可靠的做法是把信心拆成可檢查的訊號：

* 證據信心：是否有可追溯、直接支持該主張的來源。  
* 語意一致性：對同一問題多次生成或以不同表述詢問時，核心結論是否一致；注意一致不代表正確，只代表模型沒有明顯分歧。  
* 輸入敏感度：稍微改變問題、時間、角色或假設後，答案是否劇烈變動。  
* 外部驗證：能否由資料庫、工具、原文、計算、測試或人類專家獨立確認。  
* 任務校準：在與實際任務相似的歷史案例上，某個分數是否真的能預測錯誤率。

Farquhar 等人在 Nature 提出的 semantic entropy，嘗試在「意義」層級而不是字詞表面層級估計不同答案之間的分歧，並用來偵測部分幻覺。這類方法比單純讀取語氣或逐 token 機率更接近實際需求，但仍不能保證所有錯誤都會被抓到。

## 6.3 LLM 應採用「回答、條件式建議、暫緩／升級」三態決策

| 狀態 | 進入條件 | 輸出格式 | 適合創作工作的例子 |
| :---- | :---- | :---- | :---- |
| 直接回答 | 目標清楚、風險低、證據充分，或只是可逆的文字編修。 | 給出建議與簡短理由，標示採用的假設。 | 修正標點、整理已確認的角色表。 |
| 條件式建議 | 存在多個合理方案，取捨取決於價值偏好或未來情境。 | 列出 2–4 個方案、優缺點、適用條件與未解問題。 | 比較悲劇、開放式與希望式結局。 |
| 暫緩／升級 | 關鍵資訊缺失、風險高、來源衝突，或模型無法可靠辨識自己是否理解。 | 明確說明缺口，提出最少必要澄清問題或要求人類／專家確認。 | 出版前的法律、真實人物、敏感文化描寫與重大世界觀變更。 |

## 6.4 以「資訊價值」決定要不要問澄清問題

澄清問題不是越多越好。問錯問題會打斷創作，問太少則會讓 Agent 擅自補完。ICML 2024 的 input clarification ensembling 研究將輸入歧義與模型本身知識不足分開處理，說明「先釐清可能的輸入解讀，再觀察模型在不同解讀下的答案差異」是一條可行路徑。

在實務上，Agent 可使用以下判斷規則：如果不同解讀會導致不同故事方向、不同權利風險或大量重工，就先問；如果只影響可逆的措辭與細節，就提出一個明確假設並繼續。每次最多問一到三個能改變決策的問題，避免把所有不確定性都轉嫁給使用者。

## 6.5 非絕對決策的風險門檻

LLM 不應只依據「自己覺得多有把握」決定是否行動；應把錯誤代價、可逆性與人類介入成本一起納入。可以使用簡化的風險規則：

| 錯誤代價／可逆性 | 不確定性低 | 不確定性中 | 不確定性高 |
| :---- | :---- | :---- | :---- |
| 低代價、容易撤回 | 直接執行並記錄假設。 | 提供預設方案與替代方案，讓人類快速選擇。 | 先做小規模試作或保留多個分支。 |
| 中代價、可部分撤回 | 執行前簡短摘要並取得批准。 | 要求證據、比較方案與明確人工確認。 | 停止自動串接，請人類補充條件或審查。 |
| 高代價、難以撤回 | 仍需人類最終決策與獨立查核。 | 不得只用模型信心分數放行，須有外部證據與專業審查。 | 拒絕自動決策，轉交具權責的人類。 |

這個門檻特別適合 Agent：即使某一步本身看似低風險，只要它會觸發不可逆的後續動作，例如覆寫主設定、刪除分支、公開發布或把內容送入外部資料庫，就應升級為較高風險處理。

## 6.6 適用於 Agentic Writing 的不確定性協定

1. 先輸出「決策狀態」：目前任務、已知條件、未決條件、假設、受影響的文件與錯誤代價。  
2. 再輸出候選方案：至少保留兩個真正不同的方案，不把同一句話的微小改寫偽裝成多樣性。  
3. 為每個方案附上證據與取捨：哪些是來源支持，哪些是模型推論，哪些只是創作選擇。  
4. 檢查是否需要澄清：只詢問會改變方向或風險的問題；其餘內容以明確假設暫時推進。  
5. 設定停止條件：出現來源衝突、連續多輪方向漂移、設定無法一致、信號分歧升高或觸及發布／刪除等不可逆動作時停止。  
6. 執行後回寫結果：記錄採用哪個方案、誰批准、實際結果如何，作為日後任務校準資料，而不是只保存最後文字。

## 6.7 對創意寫作的特殊原則：保留「有意義的不確定性」

創作中的不確定性不一定是缺陷。有些留白是作品效果，有些角色動機必須保持矛盾，有些結局的價值就在於讀者無法得到唯一解。Agent 應區分「模型不知道」與「作者故意不說」。前者要標記證據缺口與查證需求；後者要保存為創作決策，不應為了讓設定表完整而自動補完。

因此，作品規格中最好把未知分成三欄：未決但需解決、未決且刻意保留、未知且需要外部查證。這能防止 Agent 把所有空白都當成 bug，也能避免它用看似合理的細節破壞作品的曖昧性。

# 七、給 Agentic Writing Harness 的設計建議

若把這套方法實作成 Agentic Writing Harness，建議把護欄做成系統功能，而不是只寫在提示詞裡。

| 系統模組 | 最低要求 | 可驗收指標 |
| :---- | :---- | :---- |
| Intent Ledger | 保存人類意圖、不可妥協條件、主題與禁用方向。 | 每次重大改稿都能指出哪些意圖被保留、修改或遺失。 |
| Branch Manager | 保存多個故事分支、採用／淘汰理由與回溯點。 | 可以回到任何一次 AI 介入前的版本。 |
| Role Router | 把發想、審查、查證、語言編修分配給不同角色。 | 同一 Agent 不得自動批准自己的輸出。 |
| Source Ledger | 記錄外部來源、查證狀態、引用位置與不確定性。 | 零筆未標記的外部事實進入最終稿。 |
| Diversity Check | 比較多分支的主題、結構、意象與句法相似度。 | 品質提升時，分支多樣性沒有無理由大幅下降。 |
| Human Gate | 關鍵節點要求人類明確批准，並保留批准者與時間。 | 沒有人工確認就不能進入發布或公開資料集。 |
| Provenance Log | 記錄人類文字、AI 建議、採用文字與人類改寫的區段。 | 能說明作品中哪些表達性部分由人類決定。 |

* Uncertainty Ledger：每個重大決策保存不確定性類型、證據、假設、候選方案、風險、可逆性與人工批准狀態。  
* Clarification Gate：在輸入歧義會改變故事方向時強制提問；在低風險細節上則使用可回溯的預設假設。  
* Abstention／Escalation：允許 Agent 明確暫緩，不把「必須輸出文字」當成成功條件；高風險或不可逆操作需升級給人類。  
* Calibration Set：用過去已由人類判定結果的創作案例，檢查模型的信心、分歧與錯誤是否有預測力；不要使用通用分數直接套用所有任務。

# 八、如何評估一個協同寫作流程是否健康

不能只用完成時間與讀者平均分數評估。建議至少追蹤以下指標：

* 效率：完成時間、重工次數、查證時間。  
* 作品品質：結構一致性、可讀性、角色可信度、事實正確率。  
* 創意多樣性：不同分支之間的主題、敘事結構、意象與語言特徵差異。  
* 作者性：作者能否不用看 Agent 記錄說明作品命題、關鍵取捨與每個主要角色的理由。  
* 自主能力：停止使用 AI 後，作者是否仍能獨立產生、評估與修改內容。  
* 可靠性：幻覺率、錯誤引用率、設定矛盾率與未經查證事實數量。  
* 可追溯性：是否能回溯每個重大創意決策、來源與版本。

最重要的驗收問題是：「如果刪除 Agent 的最後一版文字，作者是否仍知道自己想寫什麼？」若答案是否定的，代表系統已經從協作工具變成方向代理。

# 九、結論

AI Agent 與人類協同創意寫作的真正風險，不是 AI 會不會取代作者，而是作者在效率、流暢性與即時回饋的吸引下，逐步把最具作者性的工作——選擇、拒絕、承擔與形成自己的判斷——交給一個以高機率模式為基礎的系統。

「穆勒棘輪」可以作為提醒人們注意不可逆退化的比喻，但本題更準確的分析工具是：文化棘輪、創意同質化、認知卸載、自動化偏誤，以及 AI 生成內容的回饋污染。它們共同指向一個設計原則：讓 AI 擴張人類已經形成的意圖，並挑戰人類的判斷；不要讓 AI 在人類尚未形成意圖時替人類決定什麼值得想。

可行的長期方向不是拒絕 AI，而是建立具有創作主權、版本回溯、角色分離、來源帳本、多樣性檢查與人工發布閘門的協同系統。這樣才能同時保留 AI 帶來的效率與可及性，又不把創作者的聲音、技能與文化異質性當成可無限消耗的資源。
